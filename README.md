# YachtApp

**YachtApp** — Android-приложение для яхтсменов, предназначенное для фиксации морских погодных наблюдений и автоматической оценки штормовой/шквальной опасности в автономном режиме (без доступа к сети Интернет) на основе фотографий неба, физических датчиков смартфона и GPS.

---

## 🚀 Возможности

- **Пошаговая панорамная фотосъемка неба** по 5 ключевым направлениям (Ветровая сторона, Правый борт, Леерный/Корма, Левый борт, Север).
- **Сбор данных датчиков в реальном времени**:
  - Барометрическое давление и автоматический расчет скорости падения/роста давления (гПа/час).
  - Компас и азимут движения.
  - Ввод скорости ветра (в узлах) и признака порывистости.
- **GPS-локализация**: точные географические координаты и направление.
- **Автономный AI-анализ снимков**:
  - Компьютерное зрение на базе **Google AI Edge LiteRT** (TensorFlow Lite) с дообученной нейросетью MobileNetV3 (классификация облачности и погодных условий).
  - Спектральный пиксельный анализ соотношения Red/Blue (рассеяние Рэлея vs Ми) и плотности темных штормовых туч.
- **Матрица угроз и консенсусная оценка**:
  - Алгоритм консенсуса по 5 кадрам и динамике давления.
  - Уровни опасности: **Спокойно (`CALM`)** → **Внимание (`CAUTION`)** → **Ухудшение (`WARNING`)** → **Опасность шквала (`DANGER_SQUALL`)**.
  - Автоматическая генерация морских рекомендаций (взятие рифов, задраивание люков, использование штормовых сбруй и жилетов).
- **Локальное хранение**: полная история наблюдений в базе данных **Room**.
- **Современный UI**: декларативный интерфейс на **Jetpack Compose** с поддержкой Edge-to-Edge.

## 🤖 Обучение и пайплайн ML-модели

Приложение использует кастомную модель **MobileNetV3**, обученную классифицировать состояний атмосферы и облачности:
- `sunny`, `cloudy`, `rainy`, `foggy`, `storm`, `clear`, `snowy`, `overcast`, `hazy`, `night`.

Инструкция и скрипты для переобучения находятся в директории `scripts/`:
```bash
# 1. Установка зависимостей Python
pip install -r scripts/requirements.txt

# 2. Обучение модели на датасете (PyTorch -> ONNX)
python scripts/train_weather_model.py

# 3. Конвертация ONNX в квантованный формат TFLite/LiteRT
python scripts/convert_to_tflite.py
```

## 🔄 Процесс работы (Workflow)

1. **Захват кадров**: Пользователь делает снимки неба по 5 ракурсам.
2. **Сбор сенсоров**: Фиксируются текущее барометрическое давление (и динамика относительно прошлых замеров), показания компаса и скорость ветра.
3. **LiteRT классификация**: Каждый кадр обрабатывается локальной нейросетью LiteRT и алгоритмом спектрального анализа.
4. **Консенсус и оценка**: Анализатор строит консенсус по кадрам, вычисляет октантность облаков (0–8 окта) и степень штормовой угрозы.
5. **Инструктаж экипажа**: Приложение выдает конкретные рекомендации по парусности и безопасности.
6. **Сохранение**: Данные сохраняются в базе Room для отслеживания динамики погоды.
