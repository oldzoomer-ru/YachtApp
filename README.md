# YachtApp

**YachtApp** — Android-приложение для яхтсменов, которое помогает фиксировать погодные наблюдения в море и получать автоматический анализ погоды на основе фотографий неба, данных датчиков и GPS.

## 🚀 Возможности

- **Фотографирование неба** с камеры телефона по направлениям (ветровая, правый борт, леерный, левый борт, север)
- **Сбор данных датчиков**: компас (вращение), барометрическое давление
- **GPS-локализация**: широта, долгота, направление
- **Офлайн-анализ неба** через ML Kit (классификация облачности)
- **Оценка погоды** с уровнями угроз: спокойно → внимание → ухудшение → опасность шквала
- **Локальное хранение** наблюдений в Room-базе
- **Адаптивный UI** для разных форм-факторов (телефоны, планшеты)

## 🏗 Сборка и запуск

### Требования

- Android Studio Hedgehog+ (или новее)
- JDK 11+
- Android SDK 37 (API 37)
- Эмулятор с API 26+ или физическое устройство

### Шаги

```bash
# 1. Откройте проект в Android Studio
# 2. Синхронизируйте Gradle-проект
# 3. Запустите на устройстве/эмуляторе

./gradlew assembleDebug    # Сборка debug- APK
./gradlew installDebug     # Установка на устройство
```

## 📋 Разрешения

Приложение запрашивает следующие разрешения:

| Разрешение | Назначение |
|------------|-----------|
| `INTERNET` | Загрузка данных погоды |
| `CAMERA` | Фотографирование неба |
| `ACCESS_FINE_LOCATION` | GPS-координаты |
| `ACCESS_COARSE_LOCATION` | GPS-координаты (резерв) |

## 🔄 Процесс работы

1. **Захват**: Приложение направляет пользователя фотографировать небо по 5 направлениям
2. **Анализ**: ML Kit классифицирует облачность на фотографиях
3. **Датчики**: Записываются данные компаса и барометра
4. **Оценка**: Генерируется сводка с уровнем угрозы и рекомендациями
5. **Сохранение**: Наблюдения сохраняются в локальной базе данных

## ⚠️ Важно

- Приложение оптимизировано для **release** сборки с выделением пакетов `androidx.**`, `kotlin.**`, `kotlinx.**`
- Работа с ML Kit **офлайн** — не требует интернета для анализа
- Для получения актуальных данных погоды требуется подключение к интернету
